# Security policy

## Supported versions

We release security fixes for the **default branch** (`main`) of this repository. Older release branches may not receive patches unless maintainers announce otherwise.

## Reporting a vulnerability

**Do not** open a public Forgejo or GitHub issue for security vulnerabilities. Public reports can put users at risk before a fix is ready.

Send a private report to:

**[hello@cooperativecodebase.com](mailto:hello@cooperativecodebase.com)**

Include, when you can:

- A description of the issue and its potential impact
- Steps to reproduce or a proof of concept
- Affected URLs, components, or commit range if known
- Your contact information for follow-up

We will acknowledge receipt when possible and work with you on a reasonable disclosure timeline. We ask that you do not exploit the issue beyond what is needed to demonstrate it, and that you avoid accessing or modifying data that is not yours.

## What this policy covers

This policy applies to **this repository’s source code** and documented local development flows. Reports about **production hosts**, third-party services (Stripe, email providers, etc.), or other repositories should mention that context in your message so we can route it.

## Recognition

We appreciate responsible disclosure. Credit in release notes is offered when reporters agree and when it does not increase risk.
